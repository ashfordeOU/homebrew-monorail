# Homebrew tap for Monorail

[Monorail by Ashforde®](https://monorail.ashforde.org) is a scrolling window manager for Mac:
new windows slide in beside the one you're using, and nothing else ever shrinks.

```bash
brew tap ashfordeou/monorail && brew trust ashfordeou/monorail && brew install --cask monorail
```

Homebrew 7 and later asks you to trust a tap before it installs from it; `brew trust` does that
once. Monorail updates itself after that. This repository holds only the Homebrew cask. It
updates itself each day from [monorail.ashforde.org](https://monorail.ashforde.org/releases/latest.json).
