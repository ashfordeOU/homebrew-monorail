# Homebrew tap for Monorail

[Monorail by Ashforde®](https://monorail.ashforde.org) is a scrolling window manager for Mac:
new windows slide in beside the one you're using, and nothing else ever shrinks.

```bash
brew install --cask ashfordeou/monorail/monorail
```

Monorail updates itself after that. This repository holds only the Homebrew cask. It updates
itself each day from [monorail.ashforde.org](https://monorail.ashforde.org/releases/latest.json).
